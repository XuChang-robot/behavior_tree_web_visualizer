# 行为树可视化系统

一个基于Web的纯前端行为树可视化工具，能够解析py_trees库生成的.dot文件，并提供美观的交互式可视化界面，语言支持中、英文。

## 功能特性

- 📁 **文件解析**：支持解析py_trees库生成的.dot格式文件
- 🖱️ **交互式布局**：支持拖拽移动节点，自动布局优化
- 💾 **导出功能**：支持将行为树导出为SVG/PNG格式（保存完整树结构）

## 使用方法

### 快速启动（推荐）

双击 `launch.bat` 文件：
- 自动检测Node.js或Python环境
- 自动启动本地服务器（端口8000）并打开浏览器

### 手动启动方式

#### 方式1：使用Node.js
```bash
node start.js
```
或直接双击 `start.js` 文件

#### 方式2：使用Python
```bash
python -m http.server 8000
```
或直接双击 `start.bat` 文件

#### 方式3：直接打开
双击 `index.html` 文件在浏览器中打开（部分功能可能受限）

## 加载行为树文件

有两种方式加载.dot文件：

- **拖拽上传**：将.dot文件拖拽到页面上传区域
- **点击上传**：点击"选择文件"按钮选择本地.dot文件

## 交互操作

- **拖拽节点**：鼠标左键拖拽节点可移动位置
- **缩放视图**：鼠标滚轮缩放（倍数较小），Ctrl+滚轮缩放（倍数较大）
- **平移视图**：在空白处按住鼠标左键拖拽可移动视图
- **导出图片**：点击"保存SVG"或"保存PNG"按钮导出完整行为树
- **自动布局**：拖拽节点到新位置时，重叠节点会自动重新布局

## 显示设置

- **子节点随父节点一起移动**：勾选该选项后，拖拽父节点会带动所有子节点一起移动

## 核心功能实现

### 1. .dot文件解析

- 解析节点定义（名称、形状、颜色等属性）
- 解析连接关系（父子节点关系）
- 支持多种节点形状（矩形、椭圆、菱形、平行四边形等）
- 处理跨行属性值（如包含`\n`的标签）

### 2. 树布局算法

- 使用自底向上的方式计算节点位置
- 确保子节点围绕父节点中心对称分布
- 自动调整节点间距，避免重叠
- 平行四边形节点自动增加额外宽度

### 3. 交互功能

- 实现节点拖拽功能
- 支持子节点随父节点移动
- 实现缩放和平移功能
- 实现碰撞检测和自动布局

### 4. 连接线优化

- 使用贝塞尔曲线绘制平滑连接线
- 连接线颜色与子节点颜色相同
- 箭头自动对齐到锚点方向
- 实现连接线碰撞检测

### 5. 导出功能

- 完整保存整个行为树（不仅是当前视图）
- 支持SVG格式（矢量图）
- 支持PNG格式（位图）
- 自动计算所有节点的边界

## 支持的节点类型

| 形状 | 说明 | 典型用途 |
|------|------|---------|
| `box` / `rectangle` | 矩形（圆角） | Selector、Sequence等复合节点 |
| `ellipse` / `circle` | 椭圆 | 动作节点（Action） |
| `diamond` | 菱形 | 条件节点（Condition） |
| `parallelogram` | 平行四边形 | 并行节点（Parallel） |
